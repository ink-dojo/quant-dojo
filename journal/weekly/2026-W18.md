- `research/qlib_baseline/.venv` 独立 venv（不污染主项目）

### Phase B — 跑通 Alpha158 + LightGBM
`run_baseline.py` 完整 workflow：handler → dataset → LightGBM fit → predict → TopkDropout backtest → risk_analysis。

时间切分：train 2008-2014 / valid 2015-2016 / test 2017-2020.09.25（受 PIT 限制）。
交易成本：单边 0.15%（对齐 CLAUDE.md 红线，覆盖 qlib 默认 0.0005/0.0015）。
LightGBM 参数：复刻 qlib 官方 `workflow_config_lightgbm_Alpha158.yaml`（lr=0.0421 / num_leaves=210 等）+ seed=2026 deterministic=True。

baseline 结果（run 20260429_223928, 911 days）：
- excess **without** cost: 年化 **10.67%**, IR 1.16, MaxDD -8.3%
- excess **with** cost: 年化 **3.75%**, IR 0.41, MaxDD -9.7%
- 成本一刀砍掉 ~7pct/年化（A 股 cross-sectional ML 对换手敏感的本质）
